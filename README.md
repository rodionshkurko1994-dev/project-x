# Project X

Браузерна гра: імітація збиття повітряних цілей над Україною. Світ спільний для всіх гравців: розклад цілей обчислюється з часу, тому кожен бачить ті самі цілі в тих самих точках.

## Структура

- `index.html` — сторінка гри
- `css/style.css` — оформлення
- `js/data.js` — карта областей і міста
- `js/core.js` — світ: розклад цілей, типи цілей і комплексів, економіка
- `js/ui.js` — гравець, бій, інтерфейс, вхід і збереження
- `admin.html`, `js/admin.js` — адмінка окремою сторінкою

## Запуск

Збірка не потрібна. Відкрийте `index.html` через будь-який статичний сервер, наприклад:

    python3 -m http.server 8000

## База даних

Гра працює з Supabase: реєстрація і вхід за електронною поштою, прогрес гравців, рейтинг, ручні запуски цілей та адмінка.

- `js/config.js` — адреса проєкту і публічний ключ
- `supabase/schema.sql` — таблиці, правила доступу і функції; можна запускати повторно в SQL Editor
- `js/vendor/supabase.js` — клієнтська бібліотека supabase-js 2.117.3

Перший зареєстрований гравець автоматично стає адміністратором.

## Серверна логіка

Постріли, купівлі, продаж і нарахування коштів рахує серверна функція `game` (Supabase Edge Function), браузер лише показує результат. Гравець не може напряму змінити свій рядок у базі.

- `supabase/functions/game/logic.js` — правила гри на сервері
- `supabase/functions/game/serve.js` — підключення до бази та обробка запитів
- `supabase/functions/game/index.ts` — зібраний файл для розгортання; збирається командою `./supabase/build.sh` із `js/core.js` та файлів вище

Після зміни `js/core.js` або `logic.js` функцію треба перезібрати й розгорнути заново, інакше сервер і браузер по-різному бачитимуть світ.

# Project X

Браузерна гра: імітація збиття повітряних цілей над Україною. Світ спільний для всіх гравців: розклад цілей обчислюється з часу, тому кожен бачить ті самі цілі в тих самих точках.

## Структура

- `index.html` — сторінка гри
- `css/style.css` — оформлення
- `js/data.js` — карта областей і міста
- `js/core.js` — світ: розклад цілей, типи цілей і комплексів, економіка
- `js/ui.js` — гравець, бій, інтерфейс, збереження, адмінка

## Запуск

Збірка не потрібна. Відкрийте `index.html` через будь-який статичний сервер, наприклад:

    python3 -m http.server 8000

## Стан

Без підключеної бази гра працює в локальному режимі: прогрес зберігається в браузері, рейтинг і адмінка вимкнені. Наступні кроки: база даних із реєстрацією за поштою, потім власний домен.

Карта областей: пакет `@svg-maps/ukraine` (ліцензія CC BY 4.0).
